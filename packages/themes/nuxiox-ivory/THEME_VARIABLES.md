# Theme Variables — Nuxiox Ivory Dental Theme

This theme reads the following keys from the CMS settings.
Add these as key-value pairs in the admin settings panel.

## about.info (About tab in admin settings)

| Key | Purpose | Example Value |
|-----|---------|---------------|
| `phone` | Primary phone number | `+49 30 892 1011` |
| `email` | Contact email | `ivoryclinic.eu@gmail.com` |
| `address` | Primary location address | `Friedrichstraße 123, 10117 Berlin, Germany` |
| `hours` | Operating hours | `Mon-Fri: 08:00 - 19:00, Sat: 09:00 - 15:00` |
| `emergency_phone` | 24/7 Emergency dental hotlines | `+49 170 555 4321` |
| `facebook` | Facebook page URL | `https://facebook.com/ivoryclinic` |
| `instagram` | Instagram handle | `@ivorydentalclinic` |

## navbar.info (displayed in top bar / header)

| Key | Purpose | Example Value |
|-----|---------|---------------|
| `phone` | Header phone | `+49 30 892 1011` |
| `hours` | Header hours | `Mon-Sat: 8AM-7PM` |
| `location` | Main city badge | `Germany, Berlin` |

## footer.info (displayed in footer)

| Key | Purpose | Example Value |
|-----|---------|---------------|
| `address` | Footer address | `Friedrichstraße 123, 10117 Berlin, Germany` |
| `email` | Footer email | `ivoryclinic.eu@gmail.com` |
| `phone` | Footer phone | `+49 30 892 1011` |
